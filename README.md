# Олегуа 13 · Backend QA

Шаблон персонального QA-портфолио в чёрном, белом и синем цветах.

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Содержит адаптивную страницу и интерактивный демонстрационный пример ответов API (201, 400, 401). Пример работает локально и не отправляет запросы на сервер. Кейсы и тексты не являются подтверждёнными профессиональными достижениями.
